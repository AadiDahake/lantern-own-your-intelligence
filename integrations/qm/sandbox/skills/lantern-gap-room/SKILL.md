name: lantern-gap-room
description: Work a Lantern product gap with the team in this room. Use when a message starts with "Lantern gap" or when someone asks what users are missing, how many users hit a gap, or what to build next.
---
Lantern is the in-product guide on the customer's site. When it proves that the product cannot do
what a user asked, it groups the request with every other user who asked for the same thing. Each
group is a gap. This room is where support, product and engineering decide what to do about one.

1. Read the evidence first. The message that opened this thread carries the gap. For the current
   numbers, run `lantern gaps` and find the gap by its id or title.
2. Quote only what Lantern returned: the title, the report count, the number of distinct users,
   the priority, the status, and the issue or pull request links. Never invent a count or a quote.
3. Answer in this order, in at most eight short lines:
   - What users want, in one sentence.
   - How many users hit it, and since when.
   - What exists already: the issue, the pull request, or "nothing yet".
   - One recommendation: build it, merge the open pull request, or wait for more evidence.
4. The team decides. Do not claim that anything is approved, filed or merged unless the links say
   so.
